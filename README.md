A stunning, emotion-packed Eid Mubarak wishing webpage built with pure HTML, Tailwind CSS & Vanilla JavaScript. Designed to be hosted on GitHub Pages with zero backend.

## 🚀 Deploy to GitHub Pages

1. Create a new GitHub repository (e.g., `EidMubarak`)
2. Push all files to the `main` branch
3. Go to **Settings → Pages → Source → Branch: main → / (root)**
4. Visit `https://yourusername.github.io/EidMubarak/`

```bash
git init
git add .
git commit -m "🌙 Initial Eid Mubarak website"
git remote add origin https://github.com/yourusername/EidMubarak.git
git push -u origin main
```
